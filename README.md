# BeachPlease

## Overview
BeachPlease is a mobile app designed to aid beachgoers with real time information to help with decision-making. The app will contain several features to enhance user experience such as user registration, allowing users to log in and log out. Additionally, the app will allow users to create a profile as part of the registration process. There will be a map feature with a display of ~5 beaches for the user to see and basic information such as name and hours will be displayed for each. Upon further use, users will be able to see real-time information about the beach they are interested in such as weather, wave-height, and temperature. An added feature will also allow users to see weather conditions for a particular beach for the whole day so they can plan what is the best time to go. Another thing users are able to do is leave reviews and ratings (out of 5 stars) so other users can get more information. An average rating for each beach will be displayed and users are free to edit their reviews at any point. Lastly, there will be an option to tag beaches with certain popular activities (such as swimming or sunbathing). This will allow users who are searching for beaches to filter through for a particular activity. Each beach will be associated with the top two activities.

## Improvements since 2.4 
1. Bug Fixes:
  - **Review star ratings:** fixed an issue where editing a review removed the previously selected star rating.
  - **Back button on registration page:** added a back button to return to the login page if the user accidentally clicks to register.
  - **Optional review images:** resolved an issue where a default image space displayed even when a user did not upload one. 
2. New Feature:
  - **Beach directions:** added functionality to open Google Maps for navigation to a selected beach directly from the app.

## Setup Instructions
1. Extract the ZIP file to a directory on your machine or clone the repository
2. Open the project in Android Studio
3. Sync and build the project in Android Studio
4. Run the app on emulator. We primarily used Medium Phone API 35.
